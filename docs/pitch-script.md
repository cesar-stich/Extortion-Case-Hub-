# Demo video: narration script

The 2-minute demo video uses this narration (English). The video itself: <https://www.youtube.com/watch?v=JxxjrwvxM5M>

> The video is an **illustrative animation with synthetic data**, narrated with an AI-generated voice. The Skill has not yet run on a real NAS.

| Scene | Narration |
|---|---|
| The hook | A bus driver in Lima gets a voice note: pay a daily fee, or we burn your bus. He is afraid. So he deletes it. |
| The problem | This is the cupo, protection money. Peru recorded over twenty-six thousand extortion complaints in 2025. Transport leaders say about eighty percent of the roughly four hundred bus companies in Lima and Callao are extorted, often by several gangs at once. The evidence is scattered across drivers' phones, the numbers are disposable, and the police receive loose files they cannot verify or connect. |
| The solution | Extortion Case Hub is an AI Skill for the UGREEN AI NAS that a bus company keeps at its depot. Drivers back up threats, screenshots and payment captures into private folders. The Skill reads them and turns them into reports that can be verified. |
| How it works | It works through five NAS experts, all read-only on the originals. One inventories files and finds identical copies. One reads screenshots. One transcribes Spanish voice notes. One reads chats and the route file. And one can link depot camera events. Every file gets a SHA-256 fingerprint, and nothing leaves the NAS. |
| Driver report | For each driver, it builds a report for the police complaint: a timeline with verbatim threats, an escalation level from one to four, cupos paid, and the full evidence index. |
| Company report | For the company, it shows matches between drivers: the same collection account, the same file, the same alias, graded strong or medium. Chatbots need evidence uploaded to a cloud, and police portals receive complaints without connecting them. This Skill links cases through what extortioners cannot easily change, not their disposable phone numbers. And an anonymized indicator file lets other companies cross-check. |
| Limits | It has hard limits. It never names suspects, never contacts anyone, never advises paying, and never files the complaint. A match is a verifiable fact, not a conclusion. That judgment belongs to the police and the prosecutor. |
| Close | The NAS is what makes this possible: private local storage, permissions, and local AI, with no cloud. Today the Skill passes the official validator. It has not yet run on a real NAS, and testing it there is the next step. Thank you for watching. |
